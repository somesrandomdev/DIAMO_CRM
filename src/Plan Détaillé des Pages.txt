## 🎨 Composants Spécifiques à Développer

1. **Component: KiosqueSelector**
   - Pour les administrateurs, permet de sélectionner un kiosque spécifique
   - Affiche la liste des kiosques avec indicateurs de performance
   - Permet de basculer entre la vue globale et la vue par kiosque

2. **Component: ClientForm**
   - Formulaire complet avec tous les champs requis
   - Validation en temps réel
   - Mode édition et mode création

3. **Component: SalesChart**
   - Histogrammes pour la visualisation du CA
   - Options de période (jour, semaine, mois)
   - Comparaisons avec périodes précédentes

4. **Component: TicketGenerator**
   - Génération de tickets PDF avec template professionnel
   - Options d'impression et d'envoi par email
   - Stockage automatique dans Supabase Storage

## 📱 Responsive Design

Toutes les pages doivent être optimisées pour:
- **Mobile**: Interface simplifiée, boutons larges, formulaire en une colonne
- **Tablette**: Layout adapté avec sidebar réduite
- **Desktop**: Expérience complète avec sidebar étendue

Ce plan détaillé vous donne toutes les spécifications nécessaires pour commencer le développement de chaque page et composant. Votre schéma Supabase est parfaitement aligné avec ces besoins ! 🚀
