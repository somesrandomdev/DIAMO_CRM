## 2024-11-20 - Prevent CSV Formula Injection
**Vulnerability:** Untrusted user input (like client names or offers) could be exported to CSV format without proper sanitization. When opened in spreadsheet software like Microsoft Excel or Google Sheets, inputs starting with `=`, `+`, `-`, or `@` are interpreted as formulas, leading to CSV Formula Injection (Excel Macro Injection), which can exfiltrate data or execute arbitrary commands.
**Learning:** The application possessed a CSV export functionality that naively joined unsanitized arrays of strings. It lacked proper double-quoting for structural integrity (which prevents injection of new columns/rows) and neutralization of formula triggers.
**Prevention:** Always implement a dedicated CSV sanitization utility. Before placing untrusted user data into a CSV, ensure the data is strictly wrapped in double quotes, existing double quotes are doubled (escaped), and values starting with `=, +, -, @, \t, \r` are prefixed with an apostrophe (`'`) to force the spreadsheet to interpret them as plain text rather than executable formulas.
