## 2023-10-27 - DOM-based XSS in Transient Canvas Generation and Incomplete Sanitizer
**Vulnerability:** Transient DOM elements created for PDF/canvas generation (in `src/lib/ticketGenerator.ts`) appended raw, user-controlled data to `innerHTML` without sanitization. In addition, the custom `sanitizeHTML` function in `src/utils/security.ts` was incomplete: it incorrectly replaced `&` with `&` (a no-op), failing to actually escape ampersands properly.
**Learning:** Transient UI elements not visible on screen (like those generated for `html2canvas` or print templates) are fully functional DOM nodes and are just as susceptible to DOM-based XSS as visible UI. Furthermore, custom sanitization functions can carry subtle bugs (e.g. replacing with identical characters) which completely break the mitigation strategy.
**Prevention:** Always enforce DOM XSS protections (`DOMPurify` or rigorously tested custom sanitizers) before interpolating unknown variables into `innerHTML`, even for off-screen components. Ensure security utilities are thoroughly vetted or rely on established libraries like `DOMPurify` for HTML escaping.
