## 2025-03-05 - DOM-based XSS in HTML-to-PDF Generator
**Vulnerability:** DOM-based Cross-Site Scripting (XSS) via `innerHTML` assignment in `src/lib/ticketGenerator.ts`. Unsanitized user inputs (e.g., `client.nom`, `kiosque.nom`, `offre.nom`) were being injected directly into a temporary DOM element's `innerHTML` property for `html2canvas` to render.
**Learning:** Even transient DOM elements appended strictly for internal rendering processes (like generating PDFs) are vulnerable to XSS if they accept user-controlled data. A malicious payload such as `<img src=x onerror=alert(1)>` in a client's name would execute in the application's context. The native `sanitizeString` is insufficient for full DOM protection as it only strips some dangerous characters.
**Prevention:** Always use proper HTML entity encoding (e.g., `escapeHtml()` with `<`/`>`/`&`/`"`/`'` encoding) or `DOMPurify.sanitize()` before injecting dynamic data into `innerHTML`, regardless of whether the element is visible to the user or immediately removed after rendering.
