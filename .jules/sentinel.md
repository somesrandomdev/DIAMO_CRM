## 2025-02-13 - DOM-based XSS with html2canvas and transient DOM elements
**Vulnerability:** User-controlled inputs (`client.nom`, `kiosque.nom`, `offre.nom`, etc.) were directly injected into the `innerHTML` of a transient DOM element that was appended to the document body to generate a PDF using `html2canvas` in `src/lib/ticketGenerator.ts`.
**Learning:** Even if an element is created programmatically and only appended to the DOM temporarily for rendering purposes (like canvas or PDF generation), any script tags or malicious payloads injected via `innerHTML` will be executed by the browser as soon as the element is added to the DOM. This constitutes a severe DOM-based XSS vulnerability, bypassing typical React XSS protections which only apply to elements rendered via React.
**Prevention:** Always use `escapeHtml()` (or `DOMPurify.sanitize()`) to sanitize all user-controlled data before assigning it to `innerHTML`, regardless of how briefly the element exists in the DOM. Alternatively, use `textContent` or `innerText` to safely set text content instead of raw HTML.
