## 2025-05-25 - DOM-Based XSS in Transient Rendering Elements
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found in `src/lib/ticketGenerator.ts`. Unsanitized user inputs (`client.nom`, `kiosque.nom`, etc.) were being directly injected into a transient DOM element's `innerHTML` before rendering it to a canvas/PDF.
**Learning:** Even though the DOM element is transient (created to be rendered by html2canvas and then immediately destroyed), injecting unescaped user data into its `innerHTML` executes any embedded scripts within the context of the application. The previous `sanitizeString` method was insufficient as it only removed specific patterns but did not perform full HTML entity encoding.
**Prevention:** Always use proper HTML entity encoding (e.g., a dedicated `escapeHtml` function) or a robust library like `DOMPurify` before injecting user-controlled data into `innerHTML`, regardless of whether the element is permanent or transiently created for rendering purposes.
