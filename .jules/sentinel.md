## 2024-05-24 - DOM XSS in Canvas Rendering via innerHTML
**Vulnerability:** A DOM-based Cross-Site Scripting (XSS) vulnerability was found in `src/lib/ticketGenerator.ts`. Transient DOM elements created for PDF rendering (using `html2canvas`) populated `innerHTML` directly with user-controlled data (`client.nom`, `client.telephone`, `kiosque.nom`, `kiosque.adresse`, `offre.nom`) without any escaping.
**Learning:** Even temporary, invisible DOM elements appended to the document body (e.g., for off-screen rendering or canvas drawing) are fully parsed by the browser. Injecting unsanitized user data into their `innerHTML` immediately executes any embedded scripts, creating a severe XSS vector in an otherwise secure architecture.
**Prevention:** Always use HTML entity encoding (e.g., `escapeHtml`) or `DOMPurify.sanitize()` before injecting any user-controlled data into `innerHTML`, regardless of whether the element is visible, temporary, or meant only for canvas/PDF generation.
