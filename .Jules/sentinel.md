## 2024-05-24 - DOM-based XSS in Ticket Generator
**Vulnerability:** Found a DOM-based XSS vulnerability in `src/lib/ticketGenerator.ts` where unescaped user-controlled input (such as client names, addresses, and offer names) was directly interpolated into the `innerHTML` of a temporary DOM element used for generating PDFs.
**Learning:** Transient DOM elements created for specific rendering tasks (like `html2canvas` or PDF generation) that are appended to the document body are equally vulnerable to DOM-based XSS as permanent UI elements. The `sanitizeString` function in `src/utils/validation.ts` was insufficient for preventing XSS in `innerHTML` context as it just removes `<` and `>`, leaving other HTML entities and attributes exposed.
**Prevention:** Always apply strict HTML entity encoding (escaping `&`, `<`, `>`, `"`, and `'`) or use a robust sanitizer like `DOMPurify` before injecting user-controlled data into `innerHTML`. Created `escapeHtml` utility in `src/utils/validation.ts` to escape HTML entities for basic XSS prevention.
