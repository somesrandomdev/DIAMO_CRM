## 2026-05-28 - Data Table Action Button Accessibility\n**Learning:** Icon-only action buttons (Edit, Delete) in standard data tables frequently lack accessible names and tooltips, causing issues for screen reader users and leaving visual users without context on hover.\n**Action:** Always add descriptive `aria-label` and `title` attributes (e.g., `aria-label="Modifier le kiosque"`) to all icon-only action buttons across administrative and user-facing tables.
